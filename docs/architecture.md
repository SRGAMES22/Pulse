# Arquitetura do Pulse

## Visão Geral

- Backend: Rails API-only (JSON)
- Web: Next.js 14 App Router (SSR + Client Components)
- Mobile: React Native + Expo
- Auth: JWT
- Temas: gerenciados no frontend

## Tema Chaos (Pago)

Inspirado em Deadpool & Wolverine:
- Vermelho vivo (#E31C25)
- Preto profundo
- Amarelo dourado (#FFD700)
- Texturas estilo comic / rasgado

## Principais endpoints planejados

- Auth: login / register / me
- Posts: CRUD + feed
- Likes
- Comments
- Follow / Unfollow
- Users / Profile
