# Pulse ⚡

**Rede Social de Nicho Full Stack**  
Feed, posts, likes, comentários, upload de mídia e sistema de seguidores.

## Stack

| Camada     | Tecnologia                          |
|------------|-------------------------------------|
| Backend    | Ruby on Rails 7.2 (API) + PostgreSQL + JWT |
| Web        | Next.js 14 (App Router) + Tailwind CSS |
| Mobile     | React Native (Expo) + NativeWind    |
| Temas      | Light / Dark / **Chaos** (pago)     |

## Funcionalidades Principais

- Feed infinito com posts
- Criar posts (texto + imagens)
- Likes e comentários
- Sistema de seguidores
- Perfis de usuário
- Upload de mídia
- **Temas**: Light / Dark / **Chaos** (inspirado em Deadpool & Wolverine)

## Estrutura

```
Pulse/
├── backend/          # Rails API
├── web/              # Next.js
├── mobile/           # React Native
└── README.md
```
